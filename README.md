## The PATIENTS Framework - Programmer Documentation and Examples

This is a developer companion guide to [the PATIENTS Framework](https://open.turquoise.health/). 

The PATIENTS Framework is an open blueprint for healthcare administrative reform. It's a way to simplify the complex, fragmented, and opaque world of healthcare administration. 
The goal is to make healthcare work better for everyone – patients, doctors, insurance companies, and employers.

PATIENTS replaces each step of the healthcare transaction process with a modern, open-source, and interoperable alternative. This guide is a reference for developers who want to understand and work with the PATIENTS Framework.

- [Open Payment, Grouping and Pricing System](./open_payment_system/README.md)
  - Simple billing requires service packaging. Instead of billing patients for granular services, Standard Service Packages (SSPs) consolidate all medical services, materials, and fees associated with a healthcare procedure into a single code.
- [Universal Clinical Coverage Library](./universal_clinical_coverage/README.md)
  - Reducing administrative burden requires replacing one-off insurance authorization with simple coverage rules based on sound clinical guidelines. UCCs are an open-source, rules-based coverage determination system.
- [Open and Patient-Facing Transaction Rails](./open_transaction_rails/README.md)
  - Simple billing requires open standards for transaction information. Replace legacy ASC X12 transaction communications with modern, open replacements from the FHIR project’s Financial Module.
